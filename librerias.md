# 📑 Librerías

* _<mark style="color:blue;">**counter (version 3.11.5)**</mark>_: facilita el conteo de elementos en listas u otros iterables. Es útil para calcular la frecuencia de palabras o eventos en un conjunto de datos.
* _<mark style="color:blue;">**Dataset (versión 2.14.5)**</mark>_: biblioteca de Hugging Face que permite trabajar con grandes conjuntos de datos, optimizando el almacenamiento y procesamiento en memoria para NLP y machine learning.
* _<mark style="color:blue;">**emoji (versión 1.7.0):**</mark>_ esta librería proporciona herramientas para trabajar específicamente con emojis en Python, como la detección de emojis en cadenas de texto.&#x20;
* _<mark style="color:blue;">**html (versión 3.11.5):**</mark>_ esta librería permite analizar, manipular y generar contenido de HTML.
* _<mark style="color:blue;">**matplotlib (versión 3.7.3)**</mark>_: iblioteca popular para crear visualizaciones estáticas, animadas e interactivas en Python.
* _<mark style="color:blue;">**networkx (versión 3.1)**</mark>_: permite la creación, manipulación y estudio de grafos y redes complejas.
* _<mark style="color:blue;">**nltk (versión 3.8.1):**</mark>_ por sus siglas en inglés "Natural Language Toolkit"  es una librería muy importante para el procesamiento del lenguaje natural en Python. Proporciona funciones para la tokenización, lematización, análisis sintáctico, entre otras.&#x20;
* _<mark style="color:blue;">**numpy (versión 1.25.2):**</mark>_ biblioteca fundamental en Python para computación numérica. Permite trabajar con arreglos multidimensionales y ofrece funciones para operaciones matemáticas y estadísticas de alto rendimiento.
* _<mark style="color:blue;">**openpyxl (versión 3.1.2) :**</mark>_ es una herramienta para trabajar con archivos de Excel en formato .xlsx. Permite leer, escribir y manipular hojas de cálculo.&#x20;
* _<mark style="color:blue;">**pandas (versión 2.2.1):**</mark>_ esta librería fue diseñada para facilitar el análisis y manipulación de datos en forma tabular. Permite cargar datos de diversas fuentes (ej: CSV, Excel, SQL), limpiarlos, filtrar y seleccionar datos, realizar operaciones estadísticas y generar visualizaciones sencillas. Se destaca esta librería por su capacidad de trabajar con grandes volúmenes de datos y su integración con otras librerías de análisis y visualización de datos.
* _<mark style="color:blue;">**plotly.express (versión 5.18.0):**</mark>_ proporciona una interfaz sencilla para crear gráficos interactivos en Python.
* _<mark style="color:blue;">**psutil (versión 5.9.5):**</mark>_ es una biblioteca que permite el monitoreo del sistema, proporcionando acceso a información sobre procesos y uso de recursos como CPU, memoria y discos.
* _<mark style="color:blue;">**re (versión 2.2.1):**</mark>_ es utilizada para trabajar con patrones de texto. Permite realizar búsquedas, extracciones y manipulaciones avanzadas de cadenas de texto, lo que resulta útil para las tareas de reemplazo y procesamiento de archivos de texto estructurados.&#x20;
* _<mark style="color:blue;">**scikit-learn (versión 1.3.0):**</mark>_ ampliamente utilizada en el campo de machine learning y ofrece herramientas para tareas de clasificación, regresión, clustering y reducción de dimensionalidad, entre otras. Proporciona implementaciones eficientes de algoritmos como árboles de decisión, máquinas de soporte vectorial (SVM), y algoritmos de ensamble como Random Forest y Gradient Boosting.
* _<mark style="color:blue;">**scipy (versión 1.11.2):**</mark>_ orientada a la computación científica y matemática avanzada, con submodulos especializados en la representación y manipulación de matrices dispersas.
* _<mark style="color:blue;">**spellchecker (versión 0.8.1):**</mark>_ permite identificar y corregir errores ortográficos en texto, facilitando la tarea de asegurar la calidad del texto escrito en aplicaciones y procesos de análisis de datos.
* _<mark style="color:blue;">**tabulate (versión 0.9.0)**</mark>_: facilita la presentación de datos tabulares en formato de texto con diferentes estilos,
* _<mark style="color:blue;">**torch (versuón 2.1.0):**</mark>_ esta libería hace referencia a Pytorch, una biblioteca de aprendizaje profundo desarrollada principalmente por Meta AI y actualmente pertenece a Linux Foundation. Es reconocida por contener una de las principales librerías utilizadas para tareas de Machine Learning: TensorFlow. Esta librería permite realizar operaciones con tensores (arreglos multidimensionales parecidos a matrices), crear modelos, grafos computacionales, proporcionar herramientas y APIs para el despliegue de modelos en entornos de producción, entre otras tareas.
* _<mark style="color:blue;">**transformers (versión 4.44.2):**</mark>_ esta biblioteca pertenece a Hugging Face y es principalmente utilizada para trabajar con modelos de lenguaje pre-entrenados y tareas de NLP.  Dentro de esta biblioteca utilizaremos las clases : XLMRobertaForSequenceClassification, XLMRobertaTokenizer, AutoTokenizer,AutoModelForSequenceClassification, TrainingArguments y Trainer. Las mismas permiten utilizar los modelos importados, tokenizar acorde lo requieran los modelos elegidos y posibilitar el entrenamiento a partir de dichos modelos.
* _<mark style="color:blue;">**unidecode (versión 1.3.6):**</mark>_  se utiliza para transliterar cadenas de texto Unicode en ASCII, lo que significa que convierte caracteres Unicode (como las letras con tiles, diéresis, símbolos, o caracteres especiales) a sus equivalentes ASCII más cercanos. Esta librería resulta muy útil para normalizar cadenas de texto.
* _<mark style="color:blue;">**wordcloud (versión 1.9.2)**</mark>_: se utiliza para crear nubes de palabras a partir de texto.
